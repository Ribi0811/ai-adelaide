Generated by `scripts/check-meta.mjs` (run `npm run check-meta` to refresh).

## Script

`scripts/check-meta.mjs` is a static-analysis heuristic (does not execute
Next's metadata resolver) covering:
1. Every `app/**/page.tsx` and `app/**/layout.tsx` with a static `metadata`
   export (top-level `title`/`description`, skipping nested `openGraph`/
   `twitter` duplicates).
2. `app/blog/[slug]/page.tsx` — one row per post, sourced from `data/posts.ts`.
3. `app/[suburb]/page.tsx` — one row per suburb, sourced from `data/suburbs.json`.

It computes the *rendered* title (root layout's `"%s | AI Adelaide"` template
applied to every page except the homepage itself, which shares the root
layout's segment and isn't templated), and reports: title >60 chars,
description outside 140–160 chars, duplicate rendered titles, duplicate
descriptions, and titles that would double up the brand suffix.
